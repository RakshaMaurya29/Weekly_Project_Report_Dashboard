# 📊 Weekly Project Report Dashboard

## Project Overview

The **Weekly Project Report Dashboard** is an interactive Power BI dashboard designed to monitor weekly project execution, test progress, and team performance. It provides stakeholders with real-time insights into project status, planned vs actual execution, failed test cases, and engineer-wise performance through interactive visualizations.

The dashboard enables project managers to track weekly progress efficiently and make informed decisions using dynamic reports.

---

## Business Problem

Tracking weekly project execution manually through spreadsheets made it difficult to:

- Monitor planned versus completed work
- Identify failed test cases
- Measure engineer performance
- Generate weekly status reports
- Provide management with real-time project updates

This dashboard automates reporting and provides a centralized view of project performance.
